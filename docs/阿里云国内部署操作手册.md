# 东方有数：阿里云国内部署操作手册

## 1. 部署边界

- 国内域名：`dongfangyoushu.com.cn`
- 应用监听：`127.0.0.1:8788`
- 应用目录：`/opt/youshu/current`
- 环境变量：`/etc/youshu/youshu.env`
- systemd 服务：`youshu.service`
- Nginx 仅新增 `dongfangyoushu.com.cn` 虚拟主机，不修改原网站的域名、目录和上游端口。

## 2. DNS 解析

在阿里云 DNS 为 `dongfangyoushu.com.cn` 添加：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| A | `@` | `121.40.171.233` |
| A | `www` | `121.40.171.233` |

等待解析生效后再申请 HTTPS 证书。

## 3. 服务器首次准备

通过阿里云控制台“远程连接”进入 ECS，确认 Node.js 版本不低于 20：

```bash
node -v
nginx -v
```

创建独立运行用户和目录：

```bash
sudo useradd --system --home /opt/youshu --shell /sbin/nologin youshu
sudo mkdir -p /opt/youshu/current /etc/youshu /var/log/youshu /var/www/certbot
sudo chown -R youshu:youshu /opt/youshu /var/log/youshu
```

## 4. 上传与安装

本机项目目录执行：

```bash
npm run build
bash scripts/build-release.sh
scp youshu-release.tar.gz root@121.40.171.233:/tmp/
```

服务器执行：

```bash
sudo -u youshu tar -xzf /tmp/youshu-release.tar.gz -C /opt/youshu/current
cd /opt/youshu/current
sudo -u youshu npm ci --omit=dev
```

将 `deploy/youshu.env.example` 的内容复制到 `/etc/youshu/youshu.env`，填入真实密钥：

```bash
sudo chmod 600 /etc/youshu/youshu.env
sudo chown root:root /etc/youshu/youshu.env
```

密钥只能保存在服务器环境变量中，不得提交 Git、写进前端或通过聊天发送。

## 5. 启动独立服务

把 `deploy/systemd/youshu.service` 放到 `/etc/systemd/system/youshu.service`：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now youshu
sudo systemctl status youshu
curl http://127.0.0.1:8788/healthz
```

正常结果为：

```json
{"ok":true}
```

## 6. 接入 Nginx

先备份现有配置：

```bash
sudo nginx -T > "/root/nginx-backup-$(date +%Y%m%d-%H%M%S).txt"
```

将 `deploy/nginx/dongfangyoushu.com.cn.conf` 放到 Nginx 的独立站点配置目录。不同安装方式常见位置为：

- `/etc/nginx/conf.d/dongfangyoushu.com.cn.conf`
- `/etc/nginx/sites-available/dongfangyoushu.com.cn`

执行：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

必须在 `nginx -t` 成功后才能 reload。不要覆盖原网站的配置文件。

## 7. HTTPS

DNS 生效且 80 端口可以访问后，可使用阿里云证书或 Certbot。证书部署完成后：

- HTTP 自动跳转 HTTPS；
- 支付宝异步回调必须使用正式 HTTPS 域名；
- Supabase 登录回调白名单加入 `https://dongfangyoushu.com.cn/**`。

## 8. 验收

逐项检查：

```bash
curl -I http://dongfangyoushu.com.cn
curl https://dongfangyoushu.com.cn/healthz
curl https://dongfangyoushu.com.cn/api/deepseek/status
sudo journalctl -u youshu -n 100 --no-pager
```

浏览器检查：

1. 首页与产品页可打开；
2. 刷新 `/reports` 等前端路由不会 404；
3. 三种报告均能生成；
4. 登录、报告归档和重新打开正常；
5. 原网站仍能访问；
6. 页脚显示公司主体、ICP备案号、协议和客服信息。

## 9. 回滚

出现问题时：

```bash
sudo systemctl stop youshu
sudo rm -f /etc/nginx/conf.d/dongfangyoushu.com.cn.conf
sudo nginx -t && sudo systemctl reload nginx
```

这只会停止东方有数的新服务，不会删除或改动原网站。
