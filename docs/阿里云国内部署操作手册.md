# 东方有数：阿里云国内部署操作手册

## 1. 部署边界

- 国内域名：`dongfangyoushu.com.cn`
- 容器内应用监听：`0.0.0.0:8788`
- 宿主机仅暴露：`127.0.0.1:8788`
- 应用目录：`/opt/youshu/current`
- 环境变量：`/etc/youshu/youshu.env`
- systemd 服务：`youshu.service`
- Nginx 仅新增 `dongfangyoushu.com.cn` 虚拟主机，不修改原网站的域名、目录和上游端口。

## 2. DNS 解析

在阿里云 DNS 为 `dongfangyoushu.com.cn` 添加：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| A | `@` | `121.40.171.233` |
| A | `www` | `121.40.171.233` |

等待解析生效后再申请 HTTPS 证书。

## 3. 推荐部署方式：Docker 隔离运行

当前 ECS 已运行其他网站，东方有数使用独立容器和独立端口，避免污染现有 Node、npm 和应用目录。

```bash
docker version
nginx -v
```

创建独立目录：

```bash
sudo mkdir -p /opt/youshu /etc/youshu
```

拉取指定分支：

```bash
git clone --branch codex/report-productization --depth 1 \
  https://github.com/JohnnyCooper520/youshu-homepage.git \
  /opt/youshu/current
```

创建运行时密钥文件：

```bash
sudo cp /opt/youshu/current/deploy/youshu.env.example /etc/youshu/youshu.env
sudo chmod 600 /etc/youshu/youshu.env
sudo chown root:root /etc/youshu/youshu.env
sudo vi /etc/youshu/youshu.env
```

密钥只能保存在服务器环境变量中，不得提交 Git、写进前端或通过聊天发送。

构建镜像时传入 Supabase 的浏览器公开配置。`VITE_SUPABASE_ANON_KEY` 是 Supabase 的 publishable/anon key，不是 service role key：

```bash
cd /opt/youshu/current
sudo docker build \
  --build-arg VITE_SUPABASE_URL="https://你的项目.supabase.co" \
  --build-arg VITE_SUPABASE_ANON_KEY="你的publishable或anon key" \
  -t youshu-web:current .
```

只绑定服务器本机回环地址：

```bash
sudo docker rm -f youshu-web 2>/dev/null || true
sudo docker run -d \
  --name youshu-web \
  --restart unless-stopped \
  --env-file /etc/youshu/youshu.env \
  -p 127.0.0.1:8788:8788 \
  youshu-web:current

curl http://127.0.0.1:8788/healthz
```

正常结果为：

```json
{"ok":true}
```

查看日志：

```bash
sudo docker logs --tail 100 youshu-web
```

## 4. 备选部署方式：systemd

若以后不再使用 Docker，可按仓库中的 `deploy/systemd/youshu.service` 改为宿主机运行。目前不建议在这台已有业务的服务器上安装或升级全局 npm。

## 5. 接入 Nginx

先备份现有配置：

```bash
sudo nginx -T > "/root/nginx-backup-$(date +%Y%m%d-%H%M%S).txt"
```

将 `deploy/nginx/dongfangyoushu.com.cn.conf` 放到 Nginx 的独立站点配置目录。不同安装方式常见位置为：

- `/etc/nginx/conf.d/dongfangyoushu.com.cn.conf`
- `/etc/nginx/sites-available/dongfangyoushu.com.cn`

执行：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

必须在 `nginx -t` 成功后才能 reload。不要覆盖原网站的配置文件。

## 6. HTTPS

DNS 生效且 80 端口可以访问后，可使用阿里云证书或 Certbot。证书部署完成后：

- HTTP 自动跳转 HTTPS；
- 支付宝异步回调必须使用正式 HTTPS 域名；
- Supabase 登录回调白名单加入 `https://dongfangyoushu.com.cn/**`。

## 7. 验收

逐项检查：

```bash
curl -I http://dongfangyoushu.com.cn
curl https://dongfangyoushu.com.cn/healthz
curl https://dongfangyoushu.com.cn/api/deepseek/status
sudo docker logs --tail 100 youshu-web
```

浏览器检查：

1. 首页与产品页可打开；
2. 刷新 `/reports` 等前端路由不会 404；
3. 三种报告均能生成；
4. 登录、报告归档和重新打开正常；
5. 原网站仍能访问；
6. 页脚显示公司主体、ICP备案号、协议和客服信息。

## 8. 回滚

出现问题时：

```bash
sudo docker stop youshu-web
sudo rm -f /etc/nginx/conf.d/dongfangyoushu.com.cn.conf
sudo nginx -t && sudo systemctl reload nginx
```

这只会停止东方有数的新服务，不会删除或改动原网站。
