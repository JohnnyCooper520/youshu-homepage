# 排盘规则与验收标准

## 1. 目标

排盘层只做确定性计算，报告模型只解读已经计算出的结构。模型不得自行换算农历、推导四柱、决定子时换日或改写排盘结果。

当前计算版本：`bazi-v2.0.0`。

## 2. 当前采用规则

### 日期输入

- 默认输入为公历。
- 用户明确选择农历时，先由确定性程序换算成公历，再进入排盘。
- 闰月必须单独标明，不能只输入月份后由模型猜测。
- 非法日期直接拒绝，不自动顺延到下个月。

### 时间和时区

- 出生时间按出生地当时的民用钟表时间录入。
- 国内默认时区为 `Asia/Shanghai`。
- 当前不会把国内出生时间再次做时区平移。
- 不知道出生时辰时暂以中午 12:00 计算，并标记为“时间不确定、需要复核”。

### 真太阳时

- 默认关闭，不静默修正用户时间。
- 只有用户明确开启时才计算真太阳时。
- 经度优先使用明确输入值；没有输入时，可从受支持的城市名称表中解析。
- 无法获得经度时拒绝启用，不能假定经度。
- 修正包含经度差与均时差，采用东八区标准经线东经 120 度。

### 年柱和月柱

- 年柱、月柱以节气边界计算，不以农历初一作为月柱边界。
- 距离“节”前后 24 小时内的出生时间标记为需要人工复核。

### 子时换日

- 默认主口径为“子初换日”，即 23:00 起按次日干支处理。
- 用户可指定“午夜换日”口径。
- 有效时间落在 23:00–23:59 时，系统同时保存另一口径的四柱，报告页面必须显示采用口径，并提示两种口径可能产生不同日柱、时柱。
- 时干必须随所采用的日干重新推导，不能混用两个口径。

### 当前周期

- 流年、流月取报告生成时的 `currentDate`，不得误用出生日期所在年份和月份。
- 大运尚未进入正式报告依据；在顾问完成起运方向、起运岁数和交运时间验收前保持为空。

## 3. 报告使用约束

- 报告请求必须携带 `calculation_version`、四柱、采用口径、质量标记和当前周期。
- 模型提示词应明确：不得重新计算或纠正四柱。
- 同一用户同一出生资料和同一规则版本，应复用同一份基础命盘。
- 规则版本升级后，不覆盖旧报告；新旧报告分别保留计算版本，便于追溯。
- 命理顾问修正结论时，应记录修正原因、规则版本和样本编号，不直接改写历史记录。

## 5. 上线前仍需顾问验收

1. 最终确认产品采用“子初换日”还是“午夜换日”为默认口径。
2. 确认是否对所有国内用户默认启用真太阳时；当前安全策略为默认关闭。
3. 补足至少 50 个匿名标准样本，覆盖闰月、节气前后、23 点、跨日修正和未知时辰。
4. 验收大运起运方向、起运岁数、交运时间后，再允许报告引用大运。
5. 为每个标准样本保留顾问签字结论，后续引擎升级必须全量回归。
